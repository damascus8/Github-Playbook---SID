# Code of Conduct

We want participation in this project to be respectful, constructive, and welcoming.

## Expected behavior

- Be respectful and assume good intent while discussing technical disagreements.
- Critique ideas and implementations, not people.
- Explain context when correcting a beginner's mistake.
- Accept that projects have different requirements, risk levels, and constraints.
- Do not publish private information, credentials, harassment, or discriminatory content.

## Unacceptable behavior

Harassment, threats, personal attacks, doxxing, discriminatory language, and deliberately disruptive conduct are not acceptable.

## Enforcement

Report concerns privately to the project maintainers using the contact in `SECURITY.md` or the repository's configured contact method. Do not put sensitive details in a public issue. Maintainers may edit or remove content and restrict participation where necessary.

This policy is inspired by the Contributor Covenant approach; this concise policy is maintained specifically for this project.

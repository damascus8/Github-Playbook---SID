# Security Policy

## Supported versions

The latest version of the default branch is the only version actively maintained unless a release table is added here.

## Reporting a vulnerability

**Do not report exploitable vulnerabilities in a public issue.** Use GitHub's private vulnerability reporting / Security Advisories feature if it is enabled for this repository. Otherwise, contact the maintainers through the private reporting method configured in the repository profile.

When reporting, include:
- The affected file, version, or commit.
- The potential impact and conditions needed to reproduce it.
- A minimal proof of concept, if safe to share.
- Any suggested mitigation.

Please do not include live credentials, personal data, or unrelated confidential information.

## Response expectations

Maintainers will make a reasonable effort to acknowledge a report, assess impact, and coordinate a fix and disclosure. No fixed response-time guarantee is made by this template. Projects adopting this file should replace this section with a contact path and response expectations they can actually meet.

## Reporting a vulnerability

Do not create a public issue for a vulnerability that could be exploited. Use [GitHub private vulnerability reporting / Security Advisories](https://docs.github.com/en/code-security/security-advisories) if enabled, or contact `[private security contact or reporting URL]`.

Include the affected version/commit, impact, reproduction steps, and a suggested mitigation if known. Do not include live credentials or unrelated personal data.
